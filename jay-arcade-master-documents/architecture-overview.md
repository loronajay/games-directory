# Jay Arcade — System Architecture Overview

## Vision

Jay Arcade is a next-generation arcade ecosystem that combines:

- Browser-based gaming
- Competitive systems
- Original hardware
- A connected global player network

Built from the ground up as a unified platform, not a collection of games.

---

## Core System Structure

Jay Arcade is built as a vertical stack of four connected layers:

### 1. Game Creation (Tooling Layer)

**Textify/Blockify System** — `github.com/loronajay/textify-blockify-IR`

- Converts game logic into structured IR text and back (full round-trip)
- Enables AI-assisted development and game mutation
- Forms the foundation for scalable game production

### 2. Game Distribution (Platform Layer)

**JayArcade.com**

- Browser-based arcade platform
- Grid-based game selection
- Cross-device support (desktop + mobile)
- Automated game pipeline (build + patch system)

### 3. Player Growth & Revenue (Monetization Layer)

- Short-form content drives traffic (TikTok / YouTube Shorts)
- Players enter the platform and engage with games

Early monetization:
- Audience building
- Supporter systems

Long-term monetization:
- Subscriptions
- Competitive engagement
- Hardware adoption

### 4. Physical Product (Hardware Layer)

**Bird Duty: Lite → Future Arcade Devices**

- Battery-powered touchscreen arcade device
- Designed as a portable "playable business card"
- Bridge between web platform and physical ecosystem

## Player Experience

Players can access Jay Arcade through multiple entry points:

| Entry Point | Controls |
|---|---|
| Web | Keyboard & mouse |
| Mobile | Touch controller system |
| Hardware | Dedicated arcade devices |

All experiences connect to the same core game platform.

---

## Platform Systems

The system is powered by several key technologies:

- **Game Runtime Engine** — TurboWarp-based isolated environments
- **Unified Input System** — Supports keyboard, controller, touch, and hardware
- **Mobile Controller System** — Custom touch overlay (D-pad + buttons), fully responsive and themeable
- **Automated Game Pipeline** — Streamlined process for importing and deploying games
- **Textify/Blockify** — Full round-trip IR system for AI-assisted game creation
