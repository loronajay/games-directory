## Software Portfolio

### Jay Arcade Platform — [jayarcade.com](https://jayarcade.com)
*Solo project | Ongoing*

A full-stack competitive arcade platform hosting 9 original games with a retro CRT aesthetic. Built and maintained entirely solo using AI-assisted development workflows.

- **Leaderboard backend:** Express + PostgreSQL server deployed live on Railway with per-game secret key authentication
- **Multiplayer:** WebSocket matchmaking server handling real-time game sessions (live)
- **Build pipeline:** Python automation that extracts TurboWarp game exports, patches HTML, injects configs, and deploys — triggered by a single command
- **Mobile controller:** Custom JavaScript on-screen D-pad with 8-zone touch detection, hysteresis, gamepad support, fullscreen lock, and per-game key mapping
- **Cabinet build:** Separate pipeline generating Raspberry Pi kiosk builds (nginx + Chromium) from the same web source, with cabinet-specific CSS/JS injected at build time
- **Deployment:** GitHub Pages with custom domain; backend servers on Railway

**Tech:** Python, JavaScript, Node.js, Express, PostgreSQL, HTML, CSS, Git, GitHub Pages, Railway, nginx, Raspberry Pi
